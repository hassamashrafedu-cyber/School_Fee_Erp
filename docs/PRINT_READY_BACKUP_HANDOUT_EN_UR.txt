ENGLISH - DAILY BACKUP POLICY
------------------------------------------------------------------

1) Daily backup time: ________ PM
2) Backup file must be created every day (.backup file).
3) Keep 3 copies of backup:
   - Local school PC/Server
   - External drive
   - Cloud/offsite storage
4) Before software update/version change:
   - Take fresh backup first (mandatory).
5) Monthly restore test:
   - Restore latest backup on test PC and verify.
6) If PC is lost/corrupt:
   - Install Windows + PostgreSQL + FEE ERP
   - Restore latest .backup
   - Apply saved backend/.env settings

Important:
No backup = risk of permanent data loss.
